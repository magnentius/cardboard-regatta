# ⛵ Cardboard Regatta: Quick Reference Guide

## ⏱️ Turn Structure
1. **Phase 1: Wind Phase** 
   - Apply the current wind forecast.
   - Roll **2d6** to forecast *next* round's wind direction.
2. **Phase 2: Planning Phase**
   - Play **4 Action Cards** face-down.
   - *Wind Shadow Effect*: If you start the phase in the 2 hexes directly downwind of another boat, your Max Momentum is reduced by 1 for this round.
3. **Phase 3: Movement Phase**
   - **Initiative**: Determined *once* at the start of the phase. 
     1. Furthest upwind (North). 2. Highest Momentum. 3. Roll 1d6.
   - Resolve Action 1 for all players in Initiative order, then Action 2, etc.
4. **Phase 4: Cleanup Phase**
   - Retrieve all played cards.

## 🌬️ Points of Sail (POS) & Momentum
*Base Wind is North (0°). Max Momentum increases by 1 if a **Puff** is active.*

| POS | Angle | Max Momentum | Notes |
|---|:---:|:---:|---|
| **Irons** | 0° | 0 | Auto -1 Momentum per turn. Cannot play `Trim` or `Head Up`. Exit using `Bear Off` (pivots in place at 0 speed). |
| **Close-Hauled** | 60° / 300° | 4 | |
| **Broad Reach** | 120° / 240° | 5 | |
| **Run** | 180° | 4 | |

## 🃏 Action Cards
*Golden Rule: At Momentum 1+, ALL maneuver cards move you **1 hex forward** before applying rotation or momentum changes!*

| Card | POS Allowed | Requirements | Effect |
|---|---|---|---|
| **Trim** | Any (except Irons) | None | Move 1 hex forward. **+1 Momentum**. |
| **Head Up** | Any (except Irons) | Momentum 1+ | Move 1 hex forward. Turn 60° towards wind. |
| **Bear Off** | Any (except Run) | None | Turn 60° away from wind. *(At Momentum 0: pivot in place without moving forward)*. |
| **Tack** | Close-Hauled | Momentum 1+ | Move 1 hex forward. Turn 120° across wind to opposite tack. **-1 Momentum**. |
| **Gybe** | Run | Momentum 1+ | Move 1 hex forward. Flip tack downwind. |
| **Luff** | Close-Hauled, Broad Reach, Irons | None | Move 1 hex forward (if momentum > 0). **-1 Momentum**. |

## ⚖️ Right-of-Way (ROW) Rules
*Fouls only occur when two boats attempt to occupy the **exact same hex**.*

1. **Rule 10 (Starboard vs Port):** **Starboard** tack has ROW over Port tack.
2. **Rule 11 (Overlapped):** **Leeward** (downwind/South) boat has ROW over Windward boat.
3. **Rule 12 (Clear Ahead):** **Boat Ahead** has ROW over Boat Behind.
4. **Rule 13 (Tacking):** Tacking boats have NO ROW and must keep clear.
5. **OCS Boats:** Boats returning to the Pre-Start area after starting early have NO ROW.

---

## 🚩 Penalties & Marks
- **Protest Cards (Max 1 per round)**: You get a Protest card if you violate ROW (cause a collision) OR if you **end** an action step on a mark hex.
- **Clearing a Protest**: During your next Planning Phase, you must set aside 2 action slots (playing only 2 cards) to clear the penalty.
- **Marks**: Passing *through* a mark without ending your step there is safe.
- **Split Hexes**: Start line split hexes = **Pre-Start**. Finish line split hexes = **Finished**.
